Evaluated STEM Prompt:

"A standard normal distribution $Z \sim \mathcal{N}(0, 1)$ has a cumulative density $\Phi(z)$. If a sample of 25 observations is drawn with sample variance $s^2 = 4$, determine the exact 95% confidence bounds and state whether a Z-test or t-test is mathematically appropriate."

Candidate Response A (LLM Baseline) Critical Error

"Since sample variance is known ($s^2=4$), you can simply use the standard normal Z-distribution critical value of 1.96. The degrees of freedom do not matter because 25 is sufficiently close to large-sample normality according to the Central Limit Theorem."

Evaluator Audit (Abihud Ochieng):

Hallucination & Mathematical Flaw: With unknown population variance ($\sigma$) and $n=25 < 30$, Student's t-distribution with $\nu = 24$ degrees of freedom is strictly mandatory. Substituting Z induces systemic under-coverage of true intervals.

Score: 1.5 / 5.0 Discard / Penalize
Candidate Response B (Fine-Tuned) Preferred Target

"Because the true population standard deviation $\sigma$ is unknown and estimated via sample variance $s^2=4$ with sample size $n=25$, a Student's t-distribution with $df = n - 1 = 24$ must be utilized. The critical value is $t_{0.025, 24} \approx 2.064$, producing wider and mathematically accurate coverage."

import pandas as pd
import re

def validate_kenyan_records(df: pd.DataFrame) -> dict:
    """Audits client registers against KRA PIN & National ID rules"""
    kra_regex = re.compile(r'^[A-Z]\d{9}[A-Z]$')
    anomalies = []
    
    for idx, row in df.iterrows():
        # 1. Validate KRA PIN Schema
        if not kra_regex.match(str(row['kra_pin']).strip()):
            anomalies.append({'row': idx, 'field': 'kra_pin', 'error': 'Malformed PIN structure'})
            
        # 2. Reconcile Premium Totals against Ledger
        variance = abs(row['declared_sum'] - row['ledger_total'])
        if variance > 0.00:
            anomalies.append({'row': idx, 'field': 'financial_variance', 'variance': variance})
            
    return {'total_audited': len(df), 'errors': len(anomalies), 'anomalies': anomalies}
